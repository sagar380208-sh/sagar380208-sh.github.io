Sales Performance & YoY

Tableau parameters · dual axis · Figma layouts. Self-directed data project by Sagar Sharma.

A two-view executive dashboard where any year can become "the current year".

  • 2: Views: summary / detail
  • Any year: Selectable baseline
  • Figma: Custom layouts

The problem

Stakeholders needed to compare sales year over year to see seasonality and growth.

Build a dynamic dashboard with a selectable comparison year.

What I built

  • Parameters and calculated fields so every current-vs-previous metric recalculates on a year toggle.
  • Dual-axis sparklines with window functions marking monthly max and min.
  • Bar-in-bar subcategory comparison; a FIXED LOD histogram of customer order frequency; Figma-built backgrounds.

The result

An interactive executive tool for deep-dives into weekly trends and profit discrepancies.

How I contributed

Self-directed. I designed both views, wrote the parameter and LOD logic, built the dual-axis sparklines and designed the layout cards in Figma.

What I learned

One parameter can replace ten static charts. Letting the user choose the baseline year shifts a dashboard from reporting to exploring — as long as every metric recalculates from the same definition.
