COVID-19 Exploration & Dashboard

SQL CTEs · window functions · Tableau forecasting. Self-directed data project by Sagar Sharma.

A global dataset explored in SQL, then handed to a public Tableau dashboard with forecasting.

  • ~2%: Global case fatality rate
  • ~10%: US population infected
  • 4: Dashboard views

The problem

A global COVID-19 dataset with mortality and vaccination data, in inconsistent types.

Quantify the likelihood of dying if infected, find the highest infection rates by population, and publish it accessibly.

What I built

  • Self-joins, CTEs, temp tables and window functions for rolling vaccination counts per country.
  • Aggregates and CAST to fix type inconsistencies in death-percentage calculations.
  • Permanent views for BI hand-off; a Tableau dashboard with geographic roles and time-series forecasting.

The result

~2% global death rate among confirmed cases (deaths ÷ confirmed cases); ~10% of the US population infected (infections ÷ population). Published on Tableau Public with regional drill-down and a year-end forecast.

How I contributed

Self-directed across both halves: the SQL exploration (joins, CTEs, temp tables, window functions, views) and the Tableau dashboard it fed.

What I learned

Two rates with two different denominators — infections ÷ population and deaths ÷ confirmed cases — answer two different questions. Knowing which denominator you are using is what separates an analysis from a chart.
