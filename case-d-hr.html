HR Analytics Dashboard

Tableau · 15 charts · LOD expressions. Self-directed data project by Sagar Sharma.

An end-to-end HR dashboard — from requirements and mock-ups to a published Tableau Public build.

  • 15: Interactive charts
  • ~25%: Pay-gap pattern surfaced
  • 2: Summary / detail views

The problem

HR managers needed one tool to track employee lifecycles and departmental performance.

Build a dynamic multi-view dashboard from requirements → high-fidelity mock-ups → deployment.

What I built

  • Calculated fields with FIXED LOD expressions and IF/CASE logic for active, hired and terminated employees.
  • Sparklines for trends, heat maps for education vs performance, pie-in-pie for gender ratios.
  • Floating containers, show/hide filter menus, custom navigation between summary and detail.
  • Requirements first: user stories ("which departments lose the most people?") turned into a four-container wireframe in Draw.io — KPI band, navigation, main charts, supporting charts — then a dark theme with one colour for active metrics and one for terminations and risk.
  • Detail you only notice when it's missing: custom tooltips with a mini bar chart inside, and an employee table that carries gender icons, status flags and tenure bars in-row using a dummy-axis trick.

The result

A 15-chart interactive dashboard on Tableau Public. It surfaced a pay-gap pattern in which female PhD holders in the dataset earned ~25% more than male counterparts — an observed pattern in this dataset, not a general claim.

How I contributed

Self-directed. I translated user stories into a wireframe, defined every headcount metric as a calculated field, built all 15 charts and designed the navigation and filter behaviour in Tableau.

What I learned

The metric definition is the dashboard: deciding what "active" means mattered more than any chart. And a surprising finding — like the PhD pay pattern — is a reason to re-check the data, and to word it as what this dataset shows, not what the world does.
