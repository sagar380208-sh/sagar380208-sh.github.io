Nashville Housing Cleaning

SQL · string functions · CTEs. Self-directed data project by Sagar Sharma.

A messy property dataset made usable for market analysis.

  • 35: Missing addresses filled
  • 104: Duplicates removed
  • 3: Address fields atomised

The problem

56,000+ raw property records with inconsistent date formats, missing addresses, comma-packed address strings and duplicate rows.

Produce a clean, analysis-ready dataset.

What I built

  • Populated 35 missing property addresses via a self-join on Parcel ID.
  • Split address strings into Address, City and State with SUBSTRING, CHARINDEX and PARSENAME.
  • Standardised categorical values (e.g. "Sold as Vacant") with CASE.

The result

104 duplicate entries removed with CTEs and window functions — a fully usable dataset.

How I contributed

Self-directed. I profiled the problems, then wrote each fix — self-join to fill addresses, string parsing, CASE standardisation and a CTE-based de-duplication.

What I learned

Cleaning is a sequence of small, checkable decisions. Counting what each step changed — 35 addresses filled, 104 duplicates removed — is what makes the cleaned dataset auditable.
